# State and screen examples

Run these small programs from the repository root with
`.\.venv\Scripts\python.exe examples\states\01_basic.py` (substitute the
desired filename). Examples 01–06, 09, and 10 are graphics-independent. Example
07 opens a native RIX window; example 08 requires the pinned Pygame CE extra.

The animation example demonstrates supported clip-selection state only. It
does not claim that the current renderer performs GPU skeletal deformation.
